# Bharath Translines landing page

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository, for example `bharath-translines`.
2. Upload `index.html`, `README.md`, and the complete `assets` folder.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Before publishing

- In `index.html`, replace `91XXXXXXXXXX` in `WHATSAPP_NUMBER` with the business WhatsApp number in international format, digits only (India: `91` + 10-digit number).
- Check the fleet details, services and pricing notes.
- The enquiry form opens a pre-filled WhatsApp message; it does not store submissions on a server.
- Keep the `assets` folder and its filenames unchanged when uploading.
